Test Steps
1
Public endpoint — no token required
GET ⌄

Hits /api/public/hello. No Bearer token needed — verifies the app is reachable.

Command
curl -s http://13.210.141.214:80/api/public/hello | python3 -m json.tool
Expected Response — 200 OK
{
  "message": "Hello from public endpoint!"
}
2
Get USER token for admin
TOKEN ⌄

Requests a JWT from Keycloak using the Password Grant. The token is stored in $USER_TOKEN for subsequent requests.

get_token function call
USER_TOKEN=$( curl -s -X POST \ http://13.210.141.214:8180/realms/master/protocol/openid-connect/token \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "client_id=spring-demo-client" \ -d "client_secret=super-secret-client-key" \ -d "username=admin" \ -d "password=admin123" \ -d "grant_type=password" \ | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('access_token','ERROR: '+d.get('error_description','unknown')))" )
Expected Output
Token (first 60 chars): eyJhbGciOiJSUzI1NiIsInR5cCIgOiAiSldUIiwia2lkIiA6...
3
Access /api/user/profile with USER token
GET ⌄

Protected endpoint — requires ROLE_USER. Uses $USER_TOKEN from step 2.

Command
curl -s http://13.210.141.214:80/api/user/profile \ -H "Authorization: Bearer ${USER_TOKEN}" \ | python3 -m json.tool
Expected Response — 200 OK
{
  "username": "admin",
  "email": "admin@example.com",
  "roles": ["ROLE_USER"]
}
4
Try /api/admin/dashboard with USER token — expect 403
403 ⌄

Confirms that a user without ROLE_ADMIN is correctly denied. The -w flag prints the HTTP status code.

Command
curl -s -w "\nHTTP Status: %{http_code}\n" \ http://13.210.141.214:80/api/admin/dashboard \ -H "Authorization: Bearer ${USER_TOKEN}"
Expected Response — 403 Forbidden
HTTP Status: 403
5
Get ADMIN token for admin
TOKEN ⌄

Same admin user from master realm. Token stored in $ADMIN_TOKEN.

get_token function call
ADMIN_TOKEN=$( curl -s -X POST \ http://13.210.141.214:8180/realms/master/protocol/openid-connect/token \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "client_id=spring-demo-client" \ -d "client_secret=super-secret-client-key" \ -d "username=admin" \ -d "password=admin123" \ -d "grant_type=password" \ | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('access_token','ERROR: '+d.get('error_description','unknown')))" )
Expected Output
Token (first 60 chars): eyJhbGciOiJSUzI1NiIsInR5cCIgOiAiSldUIiwia2lkIiA6...
6
Access /api/admin/dashboard with ADMIN token
GET ⌄

Same endpoint as step 4, now with an admin token — should return 200.

Command
curl -s http://13.210.141.214:80/api/admin/dashboard \ -H "Authorization: Bearer ${ADMIN_TOKEN}" \ | python3 -m json.tool
Expected Response — 200 OK
{
  "message": "Welcome to the admin dashboard",
  "username": "admin"
}
7
View all JWT claims
GET ⌄

Returns every claim decoded from the ADMIN JWT — useful for inspecting roles, subject, expiry, and Keycloak-specific fields.

Command
curl -s http://13.210.141.214:80/api/admin/jwt-claims \ -H "Authorization: Bearer ${ADMIN_TOKEN}" \ | python3 -m json.tool
Expected Response — 200 OK
{
  "sub": "a1b2c3d4-...",
  "preferred_username": "admin",
  "email": "admin@example.com",
  "realm_access": { "roles": ["ROLE_ADMIN", "ROLE_USER"] },
  "exp": 1717000000,
  ...
}
